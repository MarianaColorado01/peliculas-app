# Películas App

Aplicación móvil para explorar películas con datos de The Movie Database (TMDB): cartelera, populares, mejor calificadas y próximos estrenos.

## Funcionalidades

- Carrusel de películas en cartelera.
- Listas horizontales por categoría: populares, mejor calificadas y próximas.
- Detalle de cada película.
- Pestañas de búsqueda y favoritos.

## Tecnologías

- React Native con Expo y Expo Router
- TypeScript
- TanStack Query y Axios
- NativeWind (Tailwind CSS)

## Cómo ejecutarlo

1. Instala las dependencias:

   ```bash
   npm install
   ```

2. Copia `.env.template` como `.env` y agrega tu token de lectura de TMDB ([créalo aquí](https://www.themoviedb.org/settings/api)).
3. Inicia la app:

   ```bash
   npx expo start
   ```
